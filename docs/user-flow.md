# 사용자 흐름

```mermaid
flowchart TD
 A[방문] --> B{시작 방법}
 B -->|예제| C[교육 준비 카드와 예시 답 불러오기]
 B -->|직접| D[생각 카드 작성]
 C --> E[생각 카드 2~5개 선택]
 D --> E
 E --> F[별자리와 원본 확인]
 F --> G[이름·대상·목표·기능·완료 기준 입력]
 G --> H{필수 조건 입력 완료?}
 H -->|아니오| G
 H -->|예| I[템플릿 기반 제작 프롬프트 생성]
 I --> J[프롬프트 확인·수정·복사]
 J --> K[외부 AI에서 구현]
 K --> L[완료 기준으로 직접 검증]
```

K·L은 외부 활동으로, 이번 프로토타입은 안내만 제공한다. 카드/조건의 수정은 이전 버튼으로 이동한다. 프롬프트는 다시 생성할 때 갱신된다. 현재 단계와 작업은 동일 브라우저에 저장한다.

## 이후 선택적 AI

명시적 요청 → 전송 카드와 비용/한도 확인 → 서버 AI 호출 → 원본과 제안 비교 → 사용자 채택 → 입력 갱신. 생성 실패 시 수동 경로를 유지한다. 미구현이다.
