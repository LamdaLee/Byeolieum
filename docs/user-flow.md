# 별이음 사용자 흐름 v0.3

```mermaid
flowchart TD
 A[생각 카드 작성 또는 예제 체험] --> B[캔버스에서 카드 2~5개 선택]
 B --> C{아이디어를 어떻게 찾을까?}
 C -->|직접| D[아이디어 이름·목적 입력]
 C -->|OpenAI 제안| E[선택 카드만 한 번 전송]
 C -->|외부 AI| F[연결 프롬프트 복사]
 E --> G{응답·근거 검증 통과?}
 G -->|예| H[후보 3개의 연결 근거 확인]
 H --> I[사용자가 아이디어 선택]
 I --> D
 G -->|실패·키 없음·취소| D
 F --> D
 D --> J[사용자·핵심 기능·확인 기준을 한 질문씩]
 J --> K[API 없이 제작 프롬프트 생성]
 K --> L[확인·수정·복사]
 L --> M[외부 AI에서 구현 후 직접 검증]
 L --> N[아이디어 보관함에 스냅샷 저장]
 D --> N
 N --> O[첫 실험 과제와 직접 확인 기준 작성]
 O --> M
 M --> P[확인 체크와 실제 결과·막힌 점·배운 점 기록]
 P --> Q{직접 확인 완료?}
 Q -->|모든 기준 체크 + 실제 결과| R[완료 기록 보관]
 Q -->|개선 필요| S[실험 도움 프롬프트 복사]
 S --> M
 N --> T[저장한 아이디어 이어서 다듬기]
 T --> J
```

AI 대기 중에도 카드 조작 가능. 요청 도중 원본/선택이 바뀌면 이전 결과를 무시한다. AI 제안은 확정 판단이 아닌 초안이다. 모바일은 드래그 대신 선택을 사용하며 개별/전체 해제가 가능하다. M의 구현·실행은 외부 활동이며, 별이음에는 기준 체크와 관찰 기록을 남긴다. 아이디어 보관함·첫 실험·기록은 API 없이 작동한다.
