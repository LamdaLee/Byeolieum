# 별이음 · ByeolIeum 기능 명세 v0.1

## 목적과 대상

막연한 생각을 카드로 모아 연결하고, 작은 웹페이지를 만들기 위한 프롬프트로 구체화한다. AI에 질문한 경험은 있지만 제작 요구사항을 정리하기 어려운 초보자가 대상이다. 서비스 주소는 byeolieum.com이다.

첫 버전의 성공 기준: 처음 방문한 사용자가 진행자의 설명 없이 예제 하나를 끝내고, 자기 조건이 반영된 프롬프트를 복사한다. AI API 없이 제공하며 외부 AI의 구현 성공을 보장하지 않는다.

## 범위와 기능

| --- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| F01 | 자유 생각 카드 | 1~500자, 최대 50개. 공백만 입력 금지. 작성·수정·삭제 가능. HTML로 실행하지 않고 텍스트 표시.                                              |
| F02 | 예제 체험      | 교육 준비 체크리스트 카드 3개와 질문 답 예시 제공. 기존 작업이 있으면 교체 확인.                                                          |
| F03 | 조합           | 2~5개 선택. 선택 여부 표시. SVG 별자리와 원본 카드 목록 제공. 선택한 카드만 결과에 반영.                                                  |
| F04 | 구체화         | 아이디어 이름·대상·목표·핵심 기능·완료 기준 5개 필수. 각 1,000자 이하.                                                                    |
| F05 | 프롬프트       | 선택 카드와 답을 템플릿에 넣어 생성. 생성 후 직접 편집 가능. 생성 기능이 AI를 호출한다고 표현하지 않음.                                   |
| F06 | 복사           | 실제 클립보드 성공 시에만 성공 안내. 실패 시 직접 선택해 복사하도록 안내.                                                                 |

| F08 | 초기화         | 확인 후 현재 작업과 저장 데이터를 초기화. 단일 프로젝트의 빈 상태를 저장할 수 있음.                                                       |
| F09 | 탐색·접근성    | 이전 단계로 돌아가 수정. 단계 전환 시 제목으로 초점 이동. 키보드 조작, 입력 라벨, 상태/오류 안내, 모바일에서 가로 넘침 없이 사용.         |

## 화면

1. 생각 모으기: 카드 입력·편집, 카드 목록, 예제 체험, 다음 버튼.
2. 생각 연결하기: 카드 다중 선택, 연결 그림, 원본 목록, 이전/다음.
3. 만들 것 정하기: 필수 질문 5개와 힌트, 프롬프트 생성.
4. 프롬프트 완성: 편집 가능한 프롬프트, 원본 목록, 복사, 외부 AI 사용·검증 안내.

## 결과물 규칙

첫 제작 유형은 작은 웹페이지다. 기본 템플릿은 모바일 지원, 예시 데이터, 필요 시 localStorage, 텍스트 안전 처리, 범위 확대 전 확인, 실행 방법·테스트 절차를 요청한다. 사용자가 선택하지 않은 카드 내용을 임의로 추가하지 않는다. 개인 정보는 외부 AI에 전달하기 전 사용자가 확인한다.

이전 단계 수정 후 결과를 갱신하려면 ‘프롬프트 만들기’를 다시 눌러야 한다. 이때 이전에 직접 편집한 프롬프트는 새 생성 결과로 대체된다. 다른 탭·기기의 동시 편집은 지원하지 않는다.

## 데이터와 운영

Project: cards[{id,text}], selected[id], brief{title,audience,goal,feature,check}, step, prompt.
로그인·서버 저장·AI 호출·결제·분석 추적 없음. 앱은 기록을 서버로 전송하지 않음. 사용자가 복사해 외부 AI에 전달하면 해당 서비스의 정책이 적용됨. 브라우저 저장 삭제/시크릿 모드 종료 시 기록을 잃을 수 있음. 프로토타입에는 민감한 실제 업무 자료를 입력하지 않도록 체험 안내에서 설명한다.

## 이후 범위

사용성 검증 후 회고 기록, 여러 프로젝트, 선택적 AI 연결 제안, 계정 동기화, 프로젝트팩을 순차 검토. 드래그 편집기, 자동 코딩·배포, 협업, 결제는 이번 범위 밖.

## 교육 상품 검증

첫 체험에서는 조합 완료, 프롬프트 복사, 외부 AI 구현 시도, 막힌 질문을 동의하에 관찰한다. 실제 측정·수익 성과가 확보되기 전 교육 효과나 매출을 주장하지 않는다. 프로젝트팩은 무료 예제 완주 검증 뒤 시범 판매한다.
